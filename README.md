# Kelvin — Releases

Official download repository for **Kelvin Node** and legacy Kelvin desktop releases.

⬇️ **[Download Kelvin Node](https://github.com/andermelo/kelvin-releases/releases/latest/download/KelvinNode.zip)**

`KelvinNode.zip` contains a signed, notarized, background-only macOS app with the
Swift executor and embedded Tuka engine. It needs macOS 15+, Xcode with an iOS
runtime, and `idb_companion`. After extracting the ZIP, move `KelvinNode.app` to
`/Applications` and follow the [installation guide](https://www.kelvincode.com/en/download).

- Website: https://www.kelvincode.com
- Changelog: https://www.kelvincode.com/en/changelog

Earlier releases contain the desktop `Kelvin.app` and its Sparkle update assets.
The current headless Node does not auto-update; check this repository for new
versions. Source code is maintained in the separate Kelvin repository.
